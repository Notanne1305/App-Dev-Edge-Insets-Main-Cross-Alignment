# Flutter Lab Activities 4 & 5

This repository contains my Flutter laboratory activities for **CCE106L (5976)**. These activities focus on understanding and applying `EdgeInsets`, `MainAxisAlignment`, and `CrossAxisAlignment` in Flutter.

## Activities

### Lab Activity 4: Edge Insets

This activity demonstrates different ways to apply padding and spacing using Flutter's `EdgeInsets` class.

The examples include:

- `EdgeInsets.all()`
- `EdgeInsets.only()`
- `EdgeInsets.fromLTRB()`
- `EdgeInsets.symmetric()`
- Combined output of the different EdgeInsets examples

### Lab Activity 5: Main and Cross Axis Alignment

This activity demonstrates how to align widgets inside `Row` and `Column` layouts using Flutter's alignment properties.

**MainAxisAlignment examples:**
- `MainAxisAlignment.center`
- `MainAxisAlignment.spaceAround`
- `MainAxisAlignment.spaceBetween`
- `MainAxisAlignment.spaceEvenly`
- `MainAxisAlignment.start`
- `MainAxisAlignment.end`

**CrossAxisAlignment examples:**
- `CrossAxisAlignment.start`
- `CrossAxisAlignment.end`
- `CrossAxisAlignment.baseline`
- `CrossAxisAlignment.center`
- `CrossAxisAlignment.stretch`

The examples cover both **Row and Column layouts** to demonstrate how widget alignment changes depending on the layout direction.

## How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in Visual Studio Code or your preferred IDE.

3. Make sure Flutter is installed and configured on your computer.

4. Install the project dependencies:

   ```bash
   flutter pub get
   ```

5. Run the application:

   ```bash
   flutter run
   ```
